# NexaForge

NexaForge is a calm, evidence-led learning companion for Islamic knowledge.

## Visual direction

- Deep ink: `#0B1220`
- Forge amber: `#F6B73C`
- Knowledge teal: `#2DD4BF`
- Paper: `#F7F8F4`
- Display type: Space Grotesk
- Body type: Inter

The interface should feel precise, warm, and quietly premium: generous whitespace,
soft cards, subtle grid texture, and amber-to-teal accents used sparingly for focus.

## Naming

Use “NexaForge” in product-facing copy. Keep compatibility identifiers such as
`DNB_BACKEND_URL`, legacy metric names, and existing API routes until the next
versioned API migration; changing those silently would break deployed clients.
